# Paper sources

`main.md` is the readable problem/method draft. `main.tex` is a shorter equivalent LaTeX draft with the same claim ceiling. `references.bib` contains 13 source-audited records; `sources.json` and `REFERENCE_AUDIT.md` record scope and status.

This is a protocol draft, not a completed paper. Authorship, venue, confirmation data and empirical results are not finalized. No PDF was generated or LaTeX compilation claimed in the starter environment.

Compile in a LaTeX-equipped environment, from this directory:

```bash
pdflatex main
bibtex main
pdflatex main
pdflatex main
```

Recheck the cited versions and venue formatting before any submission. Do not add novelty or causal claims solely because this draft uses those terms as questions.
