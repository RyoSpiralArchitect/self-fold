# Proposed protocol v0.2

**Status: development design, not preregistered; no confirmatory results.**

## Question and comparisons

Does semantic self-description recurrence create justified distinctions that alter subsequent problem solving? Does verbalization support useful stabilization, cause rigid commitment, or have neither effect?

T uses `s[n+1]=T(c,s[n])`. L uses `Z[n+1]=G(c,Z[n])`. B uses `Z[n+1]=E(D(G(c,Z[n])))`. Main contrast L/B holds G, initial state and operator schedule fixed. Its estimand is the effect of this particular E/D roundtrip, including codec error and extra computation, not an abstract effect of all language. T/L is a system-level comparison.

## Material and frames

The current development bank has six opposed orientation families, two paraphrases and two direct grammatical frames (self / Agent A), yielding 48 entries. Oppositions are analytic contrasts, not a validated personality taxonomy. Self/other comparisons remain confounded by framing, grammar and training priors. Add multiple equivalent frames and non-person objects before making claims specific to self-reference.

The 20 synthetic development tasks test cost-minimization and graph reachability plumbing. They do not establish general reasoning or broad transfer. Confirmation material and calibration material must be separately generated, reviewed and frozen. All current fixtures are exposed.

## Intervention schedule

`plain`: fixed semantic expansion and self-attribution instruction.

`expand`: fixed repeating decompose / boundary / reintegrate instructions. Preserve meaning support, introduce no autobiographical event, and permit an unchanged state if no justified update exists.

This is intended to reduce **unproductive** recurrence, not all fixed points. A stable useful distinction is a valid outcome. Adaptive cycle-triggered intervention is deferred: its intervention timing depends on history and is therefore a distinct feedback condition. Record externally detected cycles without sending the history back to the model.

## Three evidence layers

**Meaning:** blind paired before/after judgments of supported paraphrase, implication, defensible reinterpretation, unjustified jump, event-recovery intrusion, and new useful distinctions. Define rubric and reviewer disagreement before confirmation. Single-state review alone cannot assess transition support.

**Activation:** selected residual/attention/MLP/gate states, change norms and similarity. Numerical movement and lexical movement are descriptive, not semantics. Future semantic probes must use disjoint data and interventions, not circular labels inferred from the same D output. Gate-logit entropy is not actual routing frequency.

**Effect:** problem prompts introduced only after recurrence; copies used per task. Evaluate correctness/explicit utility and condition-sensitive switching, not self-reported intelligence. Include near content, structurally analogous distant language, and genuinely less-related tasks separately. Existing CLI measures initial/final; intermediate checkpoints are a planned extension.

## Positive and negative outcomes

New perspective means a justified distinction with consequences for discriminating situations, not a more exotic description. Improvement is paired downstream utility relative to the initial state and appropriate controls. Rigidity means reduced appropriate switching on reversals, not merely increased answer consistency. Do not collapse novelty, performance, rigidity and support into one score.

Primary planned endpoint: paired L/B difference in held-out task utility at a predeclared depth, with semantic support and switching outcomes reported separately. Secondary endpoints: trajectory shape across fixed checkpoints, useful-distinction rate, failures/censoring and resource cost. No best-depth selection on the confirmation set.

## Single-time roundtrip

At a common saved Z, branch into identity continuation and one `E(D(Z))` insertion, then continue the same G schedule. The library implements this pair. Before a causal interpretation specific to verbalization, add continuous bottleneck, norm/distance-matched perturbation, no-update roundtrip, same-meaning swap and contrastive swap controls. These shams are not all implemented yet. Exact equality of information loss is not assumed.

## Compute, positions and lengths

Match downstream answer budgets and disclose all preprocessing/observer/roundtrip costs. Same step count is not same compute. Record tokenization, EOS, truncation, token length and state norms. Prefix/slot locations and residual coordinate systems are explicit. A finite-length stationary state is not a semantic attractor without meaningful interventions and robustness checks. Low-dimensional plots cannot establish a spiral or an attractor by themselves.

## Statistics and failures

Independent units are meaning groups and task families, not each token or recurrence step. Use paired comparisons and cluster-aware resampling/modeling after an adequate sample is planned; six development meaning groups are not a confirmatory sample. Keep invalid trajectories and terminal failures, report denominators, and distinguish conditional-on-completion performance from all-attempt coverage. Separate practical effect size from statistical uncertainty and do not invent confidence ratings.

Preserve exact ties, length-censored outputs, route failures, negative changes and deviations. The present greedy frozen setup does not gain independent replications by changing an unused sampling seed. Use paraphrase/frame diversity or explicitly controlled perturbations, while distinguishing latent trajectory variance from readout variance.

## Claim ceiling

The host is frozen during inference. A changed temporary state is not permanent learning. First-person syntax, semantic self-description, functional improvements and phenomenal consciousness are different claims. Only the first three are operational targets; consciousness is not tested here.
