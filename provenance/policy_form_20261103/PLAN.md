# Does enumerating the cases help the native reader learn a policy?

The four-group literal trainability control ended at 112/128 native correct. Inspection of its exposed errors motivated this experiment. All 16 errors concerned rules listing multiple satisfying worlds. Eight involved exclusive-or. This is the origin of the hypothesis. [Prior experiment](../continuity_20261103/RESULTS.md)

Hold the policy, subject, site, world question, gold action, option mapping, initialization seed, group sequence, loss and update count fixed. Change the source from its disjunctive rule (DNF) to the existing four exhaustive case sentences. Use the four training groups and first two exposed development groups, self frame, wording zero, both poles, four worlds and both A/B mappings from the previous control. Check both texts against the same four-world ledger before any scoring. Use the forward case list for **both** historical order tags during fitting, matching the duplicate tag structure of the DNF control. Reserve the reversed list for evaluation. Source length, action repetition and lookup cues change together with the rendering. This estimates the effect of the complete presentation.

Use the pinned Gemma-2-2B-IT, BF16 and eight frozen workspace rows at cut 13. Capture each distinct description before constructing its recipient questions. Require the state hashes to match the archived donor records. Retain the two prior DNF-trained endpoints as fixed controls and replay their initial/final DNF decisions and A/B values at the original microbatch shape. Fit two fresh last-four-layer rank-16 q/v adapters on forward cases, one with literal text and one with the eight rows. Use the previous initialization and exact 64 group draws, AdamW at 0.0003, zero weight decay, clip 1, conditional cross entropy on the native A/B logits, effective batch 32 and microbatch 8. Record actual tokens and forwards. Save each final artifact, reload it, and verify numerical parity. The two new fits are the entire learning budget. A technical failure retains the partial trial.

At initialization and at each trained endpoint, score the rule, forward cases and reversed cases with the same native recipient. Include every logical decision and report the full-vocabulary greedy answer, coverage, forced A/B preference and ties. A/B ties fail the forced-choice metric. For each rendering, its two identical source tags are retained in the raw file. Verify their agreement, then score one distinct decision per group/pole/world/label order (64 train, 32 dev). A strict pair requires both opposed policies correct in a fixed group/world/label mapping (32 train, 16 dev). Also report the pairs correct under both forward and reversed case lists.

The primary literal engineering screen requires at least 95% native training correctness and 90% strict opposed pairs for the case-trained literal reader on forward cases. Apply the same thresholds separately to the case-trained slot reader. Crossing the order is a separate robustness check, with at least 90% of strict pairs correct in both orders. Development is descriptive. Reaching the literal screen gives a measured input control for further work on state transfer. A slot pass motivates a fresh held-out development test. If the literal screen fails, close this change of presentation and inspect the native learning path before advancing to G. The study ends after this fixed crossover regardless of outcome. G, language insertion and the independent qualification panel are outside this development run.
