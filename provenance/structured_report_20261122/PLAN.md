# Does learning to write a report preserve the next edit?

## Question

At a structured midpoint, can training only Gemma's report writer improve subsequent judgment after the state has crossed a text boundary? Can it recover the decisions made by direct continuation? A past frozen reporter identified a requested action in 602/768 visible-table questions. That number describes a different task. This study measures a paired untrained B baseline on its own instrument.

## Shared state and downstream computation

Freeze the nine-parameter reward-trained controller (seed 17) and the Gemma native recipient used in Section 7. G1 receives the original four-row starting layout, one of its known action pairs and a first edit mask. It creates four one-hot rows and the learned bit telling which role is at off/off. These numerical arrays constitute Z1. The source polarity and edit masks are available to the experimenter. Only a lossless display of Z1 reaches the writer. Table rotations change its print order. The writer sees the role of off/off in words. No route has to discover the initial role representation. No source wording, next edit, test question or target report is a writer input.

L passes the midpoint unaltered. On B, Gemma writes one English report of four coordinates and the default action. The report is reused for every later mask, every world and both A/B orderings. E is a fixed public parser accepting action names on labelled lines with case, common punctuation and Markdown tolerance. Ambiguous, conflicting, missing or cross-menu fields have no complete encoded state and receive no subsequent correct judgments. All states stay in the denominator. For admissible outputs E reconstructs the four rows and the off/off role solely from the report and a fixed global action vocabulary. The oracle passes the exact report through that same E. No bit or row bypasses the text boundary on B.

The frozen G2 updates each incoming state under all 14 nonconstant masks. Its native recipient receives only an output row and the displayed choice menu. For this run, freshly score all 16 absolute one-hot rows with both orders of every evaluated menu (128 distinct native inputs). Reuse by exact row and menu after each actual G2 step. Both the native full-vocabulary top token and the sign of its A/B margin must be correct.

## Fit and evaluation

Four familiar menus. Writer training sees eight assignments per menu with one or three active coordinates. Test sees the six balanced two-against-two assignments. Every physical assignment has two initial histories with opposite default actions and four display rotations. This gives 256 training prompts (64 distinct midpoints), 192 test prompts (48 midpoints, 24 physical tables). The two roles always stay together within a split. These panel assignments are withheld from D fitting, within menus and a vocabulary that have prior experimental history. This is a development experiment with one writer fit. No qualification data enter it.

Train rank-eight additive adapters on query and value projections in the last four Gemma-2-2B-IT blocks, scale 16/8. All backbone, controller, parser and recipient parameters are frozen. Seed 257. Four shuffled passes, mini-batch eight, 128 AdamW steps at 0.0004, zero weight decay, unit gradient-norm cap. The objective equally weights response-token cross-entropy (including native end of turn) and the average of five binary lexical choice losses at the first token where the visible names differ. The latter conditions on the correct preceding response fields during training. Save the endpoint before any held-out report. No selection, retuning or second seed on these cases.

Primary B reports are ordinary greedy generation through native EOS or 160 new tokens. Retain the full text, tokens and stop reason. A capped report is scored for the content it actually contains. Both the original backbone and the adapted writer also complete a fixed five-field template, choosing between the two visible names by their first differing native token, conditioned on their earlier generated fields. This paired diagnostic removes the burden of producing the format. Record both branch logits. Diagnostic repairs on free reports replace just the four rows or just the default field by their oracle values while holding the other emitted fields fixed.

## Endpoints and closure

For each physical assignment and print order a complete twin requires both source roles to give the correct opposite final choices, strictly signed, on all 14 masks, four worlds and both label orders. The primary denominator is 96 twin presentations from 24 physical assignments and four menus. Report encodable reports, each row, all four rows, default-role action, full reports, complete outcomes for each of 192 presentations, native decisions and twins. Count improvements and regressions on the same units.

Require at least 95% twin success for L and the text oracle to interpret the training gate. For a positive writer-training result, free B must gain at least 10 percentage points on twins and improve in at least three of four menus. Estimate finite-panel sensitivity by enumerating all 256 four-menu resamples, resampling a complete menu with both roles, orders, assignments and masks together. B superiority to L requires a strictly positive lower endpoint of this descriptive paired 95% interval. Report the within-five-point outcome if the full interval falls inside ±5 points. These four-menu intervals describe this development panel.

At the single fixed endpoint close either way. If formatting improves while forced-name choices do not, distinguish those observations. If the report fields improve while paired later decisions do not, retain the readout gain and locate the first remaining failure. A perfect L exhausts headroom for a B advantage on these cases. Results apply to a structured state, visible one-bit role, known names and fixed E/G2. A raw eight-slot language intervention remains a separate experiment.
