## Claims and stopping

This is a prospectively fixed continuation recipe, not a causal test of the hinge alone: objective, optimizer state and additional budget change together. No CE-only comparator is claimed. The old and new fresh panels differ and cannot estimate the margin intervention's transfer effect. A passed fitting gate establishes task fitting; fresh source admission establishes only the declared known-topic conditional interface. Joint-E is a newly learned encoder, distinct from prior frozen-role evidence. An admitted interface still requires a separate independent confirmation before actual G1/G2 training and EOS language/direct branch comparisons.

No fresh-score tuning, retries to green or further loss/budget search occurs within this study. Preserve first failures and all fixed endpoints. Budget remains40,000 model forwards,30million processed tokens and2,400 seconds from host initialization. Backbone hashes must match before/after. If a gate fails, report the localized limitation and return to the anchored next step in Section8. No decoder or G is fit.
