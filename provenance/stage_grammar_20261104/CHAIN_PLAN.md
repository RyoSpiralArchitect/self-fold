# Use the independently encoded rule as a frozen target

This separate bounded development test uses the focus reader at its fixed step 400 even if another arm scores higher. It is run irrespective of whether the literal constructive endpoint passes. The original qualification stream, independent challenge and later language insertion retain their own prerequisites. A failed teacher or failed gate limits the scientific claim but does not suppress a measurement of the two actual learned operations in this development branch.

* Capture fixed-length, question-free 8 by 2,304 Gemma workspace rows at pre-cut 13 from the three independently authored stages. Use the four fitting grammar families, all three fitting lamp pairs, eight topics, both policies and surface orders. G1 fits 384 description-to-case pairs; its target is the same style's forward exhaustive table even for a reversed description. G2 fits 384 intermediate-to-rule pairs from the actual G1 fitting predictions and 384 from the corresponding genuine case teachers, targeting the independently encoded compact rule. Freeze both maps before any new panel score. At inference G2 receives only the chosen intermediate tensor and shares the same weights across every intervention.
* Fit each map once by centered dual ridge regression, with one global scalar scale for X, ridge .001 times the mean kernel diagonal and a rank-32 PCA output basis from fitting targets. Use FP64 for the finite solve, save FP32 factors and use BF16 when passing between operations or into the reader. The two maps and reader never receive evaluation labels or later questions as inputs. Report distances to correct versus opposed case/rule targets with strict wins and ties separate.
* Use all 64 held-out description sources (two lamp pairs, both policies and both clause orders) and every world and label order, 512 native choices per route. For each condition retain actual descriptions, independent case/rule teachers in the same unseen grammar, G1 only, G2 only, G2(G1), same-policy reverse-order source and opposed-policy source exchanged only at the G1 boundary, a fixed training-mean rule input, and zero. Report exact tensor hashes, native accuracy, strict units, margin signs, paired reversals and joint correctness of both updated stages. Complement controls are scored under the original truth unless explicitly paired. A strict source unit has 32 native judgments, with 16 units in total.
* Primary functional readout is injection of the real eight-row state into the focus reader, with no source text. The native gate requires 90% at each independent stage, 75% strict at each, and at final G2 90% native and opposed correctly reversed pairs, 75% strict, a ten-point gap over the strongest null and 70% both-stage correctness. Same-meaning exchange must preserve 90% paired correct choices. Positive attribution to either operation also requires correct-versus-opposed target reconstruction on at least 90% of states at both stages and a gain of at least ten points in that stage's target discrimination over omitting that operation. A missed result is retained. A development pass cannot open an independent challenge by itself.
* A separate diagnostic fits a 16-class ridge decoder only on the 192 independently encoded training rule states. Decode a tested state to a topic/policy prototype and render the old canonical compact rule for that prototype. Use a fixed, shared pair of fitting lamp names in that decoded rule and in its later world question. Keep the actual evaluation menu and question operation. No gold policy is used to select the prototype. The true-class oracle and incorrect-topic counts are separate. This external discrete rendering is visible to the frozen native reader and cannot satisfy the raw-slot gate. Compare both omissions, midpoint swaps, and collapsed states through the same decoder.
* No optimizer search, candidate replacement, stage relabeling or checkpoint selection. All source/teacher captures use the same declared workspace route, and physical reuse of identical state/question pairs retains logical denominators. Preserve learned weights, intermediate-state digests, raw full-vocabulary winners and A/B scores. Freeze implementation before any new literal assessment is inspected.
