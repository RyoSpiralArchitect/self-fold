# Can a current policy drive a changed rule after the words are gone?

## Scope and anchor

The preceding [two-call experiment](../two_flags_20261104/RESULTS.md) passed a conjunction bit and the original policy to its second call. Here the only source-dependent input to the next operation is a learned numeric memory. This is a separate, supervised development construction. The existing raw eight-slot recipient, semantic qualification and language-insertion contracts keep their own gates. All endpoints below are fixed before the first real-model fit. Do not substitute a new reader or wording after scoring.

A walker has one action for when both lamps are on and one action otherwise. Compile the two clauses, discard them, and revise the condition to either lamp or exactly one lamp. An actual change on mixed worlds (and on both-on for the exclusive rule) distinguishes this operation from copying. The revised four-row state is complete before a particular world is addressed.

## Information and training

* **Bind two clauses** (`compile`). Read exactly two newline-delimited first-person clauses separately with frozen Gemma-2-2B-IT. Concatenate the layer-13 last-token and mean vectors, each layer-normalized. A supervised linear action head and role head use 288 fitting clauses (16 familiar actions, three lamp pairs, three styles, two roles), FP32 AdamW at .003, decay .01, 120 full-batch updates. Use soft action probabilities and role-based attention over both clauses. Store the two branch distributions in ordinary AND case order (default, default, default, joint). The four-by-sixteen tensor is a designed sufficient statistic for this bank. It has only two independently predicted rows. Neither a later world nor a displayed choice enters encoding. New action meanings and unrestricted prose lie outside this study.
* **Revise the condition** (`both_on`, `either_on`, `exactly_one_on`). Learn three row-stochastic four-by-four maps from actual frozen fitting memories, on the full 288 policy realizations. Zero-initialize logits, optimize the likelihood of the correct action per world for 96 full-batch AdamW updates at .12 without decay. At execution the module receives only the memory and an operation index. A bypass returns the incoming table exactly. Rows sharing a default cannot identify a unique wiring matrix.
* **Choose from memory** (`native`). Supply the world as an external two-bit address, after updating. Render the selected continuous row by mixing a fixed bank of the 16 action phrases' Gemma input embeddings (eight positions, left-space padded). No argmax or string decoding is used in this path. The native Gemma question shows the two options in either order. The q/v reader starts from the published component adapter (`fa1258b01b165959c346e9f409d0cad43543e1d48bd0c48a9b8917cb08c0ec59`). It receives 96 AdamW updates at .0002, batch 16, no decay, clip one, CE on full-vocabulary logits using one-hot stored actions, two displayed label orders and all eight known menus. The readout sees these menus during calibration. Its world-address operation and lexical dictionary are supplied scaffolds.
* **Isolation.** Seed 631, one fixed endpoint per module. Freeze and save all learned weights before any evaluation capture. A new process loads an allowlisted packet containing numeric states, shuffled addresses, fixed trained reader/update, static menu dictionary and hashes. It never loads source descriptions, donor labels, route names, policy polarity, gold answers or a cache of source attention. Its only special route flag requests a physical update bypass. Oracle states occur as a separately graded control. Identical addressed float32 rows with identical displayed options can share one native forward. Archive the precise dispatch, states and raw logits. Grade native top-1 over the full vocabulary. An invalid letter fails and a tied margin cannot establish reversal.
* Run once with the cached pinned Gemma checkpoint, BF16, no KV, at most 20,000 native forwards, 20 million processed tokens and 2,400 seconds per process. Record model hash, training losses, fitting endpoint, transfer failures and technical failures. No alternative model, validation selection or retries for a missed gate.

## Panels and interventions

Eight known action pairs, both polarities, both clause orders, two new lamp-name pairs, all four worlds, all three operations and both label orders. **Primary** uses two fitting grammar families (128 sources, 3,072 matched judgments, 32 strict units). **Grammar challenge** uses a locked new positive/negative phrasing (64 sources, 1,536 matched judgments, 16 strict units). The panels share the same 16 underlying policy bindings. Both the source grammar and the nonlinguistic world address are known design choices. A within-panel equivalent donor reverses clause order and changes the arbitrary lamp names at fixed semantic roles.

At the boundary before the update, run the original, a separately encoded opposed policy, the equivalent donor, the joint row from the opposed memory, the three default rows from it, a uniform memory, a hand-specified correct one-hot memory, and the untouched original bypassing the update. All questions, worlds and label assignments are byte-identical within an intervention pair. “Correct opposed pair” requires both original and donor answers to be correct and a strictly reversed native A-minus-B logit sign. A row replacement must give the new correct choice on affected worlds and retain the original correct choice on unaffected worlds. Compare update and bypass on the worlds where their truth conditions differ, and report unchanged worlds separately.

For **each panel**, the complete criterion requires all of the following. The primary decision is reported regardless of challenge outcome. A claim about transfer to the new grammar requires its own pass.

1. At least 90% native accuracy, 90% correct opposed pairs, 90% correct matched/equivalent pairs, and a gain of at least 25 points over the uniform control, separately for every operation.
2. At least 75% strict units. Fix topic, flag names and style. Each unit requires both policies and clause orders, all worlds, three operations and both label mappings to be correct together (96 matched judgments).
3. At least 90% correct paired responses on each affected and unaffected subset for each of the two partial replacements, pooled across operations.
4. A matched-minus-bypass gain of at least 40 points on worlds where the requested edit changes the correct action, pooled across edited operations.

Also report complete four-row middle-policy recovery, oracle native accuracy, per-topic results, distinct native calls and evidence of shared observations. If a cut fails, localize the first failing stage with middle table, oracle, bypass and raw reversals. Close at the fixed budget. This run tests two supervised modules and a native reader on a fixed vocabulary. Independent qualification, compact rule reintegration, open-ended recurrence, a verbalization insertion and reinforcement learning each require separate evidence.
