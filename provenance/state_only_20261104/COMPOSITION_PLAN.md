# Can the frozen update consume its own output?

This follow-up was designed after inspecting the one-edit results and routing weights. It reuses the 128 familiar-grammar primary sources that passed all one-edit criteria. It is an additional diagnostic on known policies. Seal this program and its criteria before scoring chained native answers. New training, model selection and new grammar selection have a budget of zero.

A second operation means “replace the preceding trigger by this trigger, retaining the default and switched actions”. Both the old and the requested trigger come from both-on, either-on and exactly-one-on. Each of the nine ordered pairs is meaningful, including three redundant revisions. An independent executor can recover the default from off/off and the other action from a distinct occupied row after every legal first edit. Thus the current state is in principle sufficient to realize the assigned edit on this bank.

1. Materialize the entire actual FP32 output of the first learned update from the saved midpoints, without consulting any individual world. Preserve all four case rows and their soft values. Verify source, reader, update and packet bindings against the completed one-edit study.
2. Give these tables to the original blind decision program in a fresh OS process. Supply only the second operation, address and menu, as in the one-edit study. Independently run the actual post-first-update table of an opposed policy at the second boundary and physically bypass the second edit. No source text or key is passed. The first operation is absent from the second call. Neither weights nor the table are canonicalized between updates.
3. Grade all 128 sources × 9 requested pairs × 4 worlds × 2 mappings (9,216 matched judgments). Each cell has 1,024 matched, as many opposed and bypass judgments, and 32 strict units requiring both policies, wording orders, worlds and label mappings. Opposed pairs require both native correct and a nonzero margin sign change. In a redundant edit, correctness should be preserved. Where the triggers differ, count edited and bypassed correctness on just the affected worlds.
4. Call reuse across the tested sequences supported only if all nine cells have at least 90% native and correctly reversed pairs and 75% strict units, and all six nonredundant cells improve on bypass by at least 40 points on changed worlds. Otherwise identify failing incoming edits; publish every cell and stop. Repeated paths on the same eight topics are dependent. Independent validation, feedback-based learning, and the general slot protocol retain their own conditions.
