# One joint source-encoder and native-recipient candidate

The two full-vocabulary recipients and the conditional-label recipient are closed at their fixed endpoints. They failed with frozen workspace E. The following is a new construction experiment on exposed development data, with one fresh configuration. It does not isolate the causal effect of changing E alone, because the architecture and learning rate also change.

Use frozen Gemma-2-2B-IT, the same source data, the original group/frame/stage/wording schedule, and the same task pairs. Add source-scoped rank 16 q/v LoRA to decoder layers 9 through 12, immediately before the pre-cut 13 carrier. Keep the task-scoped rank 16 q/v LoRA in layers 22 through 25. Source seed 947 and task seed 47 independently initialize zero-up factors. The source forward takes only the current source description and the existing eight workspace tokens. It receives no question, truth labels or supplied target answer.

During training, the native source forward stops exactly at the input to layer 13 and retains the eight differentiable hidden rows. It uses the original fixed 256-token source geometry. An exception carrying the observed tensor ends the prefix forward; it supplies no replacement state. Only the source-scoped factors are active. The task then receives that tensor and its later question with only task factors active. Gradient checkpointing is disabled, because recomputation outside these contexts would change scope.

Each microbatch contains eight questions of one source variant, covering its four worlds and both label mappings. Encode that source once, reuse the same gradient tensor eight times, and backpropagate conditional A/B cross entropy on the unchanged native post-softcap logits. Four opposed/order source variants make an effective 32-question batch. Use AdamW learning rate 0.0003 for both modules, zero weight decay, global clip 1, 256 updates. Every update requires a finite nonzero gradient in both modules and no backbone gradient. Match initial zero-encoder source activations to the native E path at identical geometry before fitting.

Save both learned adapters with their source/data/base-host/role bindings. Freeze both at step 256, capture every train/dev source and both teacher representations with learned E before constructing evaluation questions, then reuse each frozen state unchanged across questions. Use the same six matched/opposed/empty/zero/random/unrelated routes. The previous immutable literal-text baseline remains referenced. Null latent states are read by the same learned recipient; no source-dependent reference text is constructed.

The fixed recipient screen remains 90% native full-vocabulary greedy stage2 accuracy, a 10-point advantage over the strongest fixed null and 75% compound correct polarity/order units. Source and stage1 results and exact native ties remain visible. Canonical stage2 teacher texts still duplicate the source-order tag. A pass is an interface milestone on an exposed development panel, preceding actual G composition and independent confirmation. A failure ends this single configuration. No learning-rate or layer search follows within this phase.

The previous 24-group sealed qualification commitment remains untouched. A new two-step confirmation panel and independent transition review are pending.
