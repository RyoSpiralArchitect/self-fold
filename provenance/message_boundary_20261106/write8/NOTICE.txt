SELF-FOLD refits small state-update controllers using archived Gemma reports
and native row scores. The initial text-channel readout uses an existing
trainable start address. The original report corpora, model outputs and first
failed controller results are preserved; this follow-up adds new controller
weights, exact archived replays and separately versioned trajectory evidence.
