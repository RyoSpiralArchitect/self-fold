## Question and exact information boundary

Write8 found that identical report/row-contrast inputs can require opposite
roles. Its decoded comparator used source-pole information absent from its
learned text pointer. Does explicitly carrying the same source reference
repair the learned text path, without changing its parameter count or budget?

Derive one bit **once** from the byte-recovered initial compiled action memory:
the canonical option slot of member 0 in the fixed sixteen-action bank. The
two source rows must be exact one-hot partners. No policy text, source-pole
label, current target bit or future instruction enters this extraction.
The bit is a **supplied reference with engineered copying**, not learned
retention. Its origin and one-bit bandwidth are part of the intervention.

The learned text reader uses the same 32-dimensional hashbag and 73 parameters
as write8. The reference exchanges its two pointer roles; this is a specified
routing operation with no new fitted weights. The integer start address is
unchanged. Every subsequent boundary carries `(new report features, old
reference)`. Later updates must copy the incoming bit; refreshing it from
source IDs or labels is forbidden.

The decoded comparator exposes its existing operation: absolute action slot
from the saved text and fixed option bank, then slot XOR carried reference.
Its original 9-parameter actor stays frozen. Missing mentions retain the
archived role-zero fallback. Matching this reference does not make the
handwritten lexical decoder and learned features the same extractor.

## Acceptance and bounded closure

Report directed and natural styles independently. A style clears this
**scaffolded readout gate** only if every seed reaches at least 90% primary
complete histories and 90% unfitted-mask histories, gains at least 20
percentage points over its unreferenced fit, and loses at least 20 points
when its reference is fixed to zero. Initial completeness must be 448/448.

For intervention consistency, pair the 32 × 14² distinct first-two-update
units. Among units fully correct under intact reference, at least 90% must
choose the opposite action in every world/order after reference inversion.
Role exchange is built into this routing interface; that conditional flip is
an implementation/causal-consistency check, not independent evidence that a
model spontaneously learned reference semantics. Equivalent donors must
retain the same native accuracy. All-four gates require all four updates,
all four worlds and both answer orders. Counts reuse a small menu bank;
do not treat histories or individual decisions as independent tasks.

Always audit saved report-input conflicts with/without the reference and
separately tabulate decoder correctness when realized output equals versus
differs from the instruction. The directed prompt asks about the instruction;
a passing correct-history score does not establish faithful error reporting.
These audits are predeclared diagnostics and do not change fitting or gates.

Complete after the 12 fixed fits, 42 evaluations, all checks and a fresh-process
reduction. If a style fails, preserve the first result and close that branch
with its remaining factor; no seed, feature, parser or budget search. Neither
success nor failure establishes general semantic recurrence, learned reference
retention, unseen-vocabulary transfer or independent six-check qualification.
