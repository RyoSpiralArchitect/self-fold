# Can a neutral reference make a relative difference usable for one source?

This follow-up starts after the [negative two-arm comparison](RESULTS.md). The raw readout correctly ordered all 48 opposed pairs, but its fixed threshold correctly classified only 48/96 individual donors. The original outcomes and the construction of the crossed panel are known. No model has scored the crossed wording or the centered geometry at this seal. Freeze the script, panel, endpoint reducer and plan before observing either. This is a separate development diagnostic, with zero gradient updates and one new checkpoint run.

## Available information and comparisons

Use the same frozen Gemma snapshot, native tokenizer, cut, eight slots and 256-token description-only geometry. Replay the raw donors for all 192 original train and 96 original dev descriptions. Require all 288 source-state hashes and the original labelled/sham first-mention margins to match the preceding run (absolute margin tolerance 1e-5). Add the fixed 96 crossed dev descriptions. The abstract policies and families overlap across the two dev panels.

For each source x, form a reference n(x) by replacing each of the two tray adjectives with “metal.” Check exactly two single-token substitutions, equal native length, identical capture positions and one common replacement token. Capture both descriptions without questions or truth labels. Reuse exact duplicate captures by text. This reference can be constructed from one initial source. It adds a second encoder input and requires access to its text. It cannot by itself center a later recurrent state when that source text is unavailable.

Fit two fixed Euclidean centroids on the **original train groups only** for each feature: raw slots, raw minus reference slots, and reference slots alone. Repeat with the previous six flipped sites per family. No learned encoder or gradient optimizer. For each feature and label use the train class-mean midpoint as threshold. Report signed copper margins and treat a tie as unsuccessful.

* **First mention** asks whether the first tray named is copper. This label reverses with clause order.
* **Action at the trigger** asks whether copper is prescribed when the policy's triggering condition holds. Use the public truth ledger when all flags are on for the train families, the single empty world for exclusion, visitor mode on for scope, and request on / override off for priority. This one action label stays fixed across both clause orders. It captures a single policy distinction, short of evaluating the full rule on independent tasks.

## End and next decision

Evaluate both the original and the crossed panels once. The primary operational question is single-source trigger-action accuracy on the crossed panel and joint correctness for both word orders of the same policy. Each group supplies both policies. Give family strata and all 48 order pairs. Class and site counts are balanced. A descriptive lexical endpoint requires ≥80% absolute first-mention accuracy on the crossed panel and ≥10 percentage points above the stronger of the corresponding shuffled-label and reference-only accuracies. For operational trigger access require the same accuracy and null margin **and** ≥80% joint order-pair correctness (both phrasings individually right). Compare raw and centered features separately. Prefer the single-encode raw readout if both meet a criterion. Credit centering as a practical improvement only at ≥10 points over raw on the same endpoint. Reference-only is a control.

A readout that transfers only mention order motivates a separate train-only rule/application readout with independently crossed wordings at training time. If neither readout transfers either distinction, close these geometries; the next bounded comparison may vary the description-only capture under a fixed independent recipient. If a policy readout transfers, freeze it as a diagnostic and test functional use in the native recipient before advancing to roundtrip or G. Stop at the first identity, layout, replay or completeness failure, preserve it, and classify the affected comparison as invalid. This run ends after this single readout panel. G, independent human review, qualification and any multi-step pilot require their own entry conditions.
