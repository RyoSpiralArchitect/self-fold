# Resolving a veto already present in a policy

A walker names a regular route and an alternate route. The left lamp triggers the alternate. The right lamp cancels it. When both lamps are on, the original policy already entails the regular route. The one-step operation makes this consequence explicit in the state. The updater sees neither a new instruction that specifies the answer nor the later world. Identity and update are scored against the same truth table.

On the first wording panel a structured G made 672 of 768 change-required policies newly correct in every world and both label orders. The eight-slot native G made 0 of 64 newly complete in its separate panel. Fresh wording did not replicate the full structured endpoint. The formal 24-group qualification set is still unopened. Human transition review was deferred. [Primary prospective plan](PLAN.md) · [Six evidence records](gate.json)

## A frozen role bit and a learned one-step update

Gemma encoded four text fields before any question. Two source clauses named the actions in either order. Two others named the trigger and possible veto. Ridge heads inferred the actions, their roles and both predicates. The base action table, a bit identifying the role in its first row, and the inferred veto constituted the incoming state. The bit writer and the two row pointers were the unchanged reward-trained seed-17 parameters from the [one-bit experiment](../role_memory_20261104/RESULTS.md).

The new G learned twenty overwrite logits from the action targets of 2,560 fitting sources, with 128 updates. It could keep an existing row or replace it with the retrieved regular row. The resolved state consumed the veto and updated its reference-role bit. An external world address then selected the row for the frozen native Gemma choice. The fixed field interface, two-role vocabulary, time of world addressing and ability to copy an existing row are supplied parts of this experiment. G used supervised action targets. The earlier training of the bit used scalar native-choice rewards. [Fixed fitted weights and thresholds](structured/fit_closed.json)

Each panel has eight known menus, four triggers, five veto possibilities, two action assignments, two source orders and two previously unseen styles. A policy is complete only if all four worlds and both native A/B orders succeed. Of the twenty trigger/veto combinations, twelve overlap and eight require stability. The paired 95% topic-bootstrap interval was [30.21, 30.21] points because every topic had the same net gain. On the new panel it was 29.43 points [26.69, 31.25]. Stable completeness fell to 77.34% [71.48, 81.25], missing the fixed 90% floor. These intervals resample the known menus. Wording families and repeated answers are not independent population samples. In both panels the learned G emitted exactly the rows obtained by applying the formal veto at answer time to the same inferred premises. Its advantage over identity shows the value of resolving a pending condition for the fixed row reader. It supplies no advantage over that direct interpreter.

## What the carried bit contributed

Complementing the base trigger and exchanging the two branch roles gives two histories with the same base action at every world. Where the veto is active, each must return to its own regular action, so their correct answers are opposite. In a separate intervention we gave both histories the very same saved floating-point table and veto and supplied the bit from each source. Erasing the bit then makes both inputs identical. This is an experimenter-constructed twin; none of the 1,280 independently encoded twin tables per panel were bitwise identical.

| --- | ---: | ---: |
| Both veto-world choices correct with reversed margin, bit present | 3,840/4,096 | 3,616/4,096 |
| Same comparison with both bits erased | 0/4,096 | 0/4,096 |
| Both non-veto choices correctly preserved, bit present | 5,888/6,144 | 5,448/6,144 |

Counts are scored directions, including both answer orders, rather than independent pairs. The zero after erasure follows from identical inputs and opposite targets. The empirical result is the number resolved with the learned bit intact. The primary met all bit-specific thresholds. The new panel missed the 90% non-veto preservation floor (88.67%). ## What happens when the state is written out?

The structured D renders each numerical row into a world/action sentence using a fixed vocabulary. The literal action reader then sees only the rendered text and the later question. A separate path re-encodes the four emitted rows with Gemma before making the native decision. These are tests of current actions through a designed table format. Free verbalization is examined separately below.

On the primary panel the literal D(G) answers were 8,158/10,240, 34 below the 80% floor. Re-encoding the same descriptions gave 9,984/10,240. D(E) before the update gave 6,584/10,240 as text and 8,192/10,240 after re-encoding. Even on the 1,152 correctly resolved tables, the literal reader gave 7,412/9,216. This separates difficulty using the written cases from errors in constructing them.

We froze this miss before a single reader-only continuation. The new adapter received 192 updates (3,072 labels) on formally authored tables from four menus. E, G, the role bit, the native row reader and the renderer were fixed. The test used two new source forms and a new question. Of 1,016 distinct literal test inputs, none occurred among the calibration prompts. Tables, menus and native row inputs can recur, and every menu was familiar to the original model interface. ## The original eight-slot path

The frozen Gemma workspace E used eight rows at cut 13 with a fixed 256-token source forward. We fitted a single ridge transport from actual post-writer rows of all four native G prompts to the independently encoded, formally supported successor. The 64 fitting sources contributed 256 source/operator pairs and 2,048 aligned rows. Stable sources targeted their own text. Every operator saw the same already stated policy. This was the formal ridge baseline, with no independent human validation of usefulness.

On four known menus (128 fresh descriptions), native decisions were 503/1,024 for E, 500 for plain G, 503 for decompose, **507 for boundary**, and 506 for reintegrate. The independently encoded target gave 504/1,024. The zero and unrelated controls each gave 512/1,024. Boundary and the naturally opposed state yielded zero correctly reversed pairs out of 1,024. Neither the 64 change-required nor the 64 stable source policies had a fully correct boundary result. Adding the neutral question prefix gave 512/1,024. The model's literal access to the original sources on these questions was 523/1,024, limiting attribution to the transport alone. Native free D reached EOS on all 16 selected E states and all 16 corresponding boundary G states. Every output was the same request for the current description, with 13 emitted tokens. D(G) text and its re-encoding each gave 64/128 on the subsequent choices. No answer was excluded for stopping. [All generations and EOS receipts](raw-bound/free_text.jsonl)

The first run completed the transport, 128 source records and all 32 free generations, then rejected the native recipient's binding before scoring. Its task adapter belonged to the archived 1,024-token native host. The G/D host had a 512-token ceiling and a learned writer transport. The repair instantiates the actual distinct task geometry over the same frozen backbone and shares the compute meter. It preserves the loader checks. The continuation reloaded the original map with zero refits, reconstructed the same source and boundary hashes, and used the original 32 generations byte for byte. No candidate native scores preceded the fix.
