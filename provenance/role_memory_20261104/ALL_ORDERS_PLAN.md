# Inspect every four-edit order at the frozen endpoints

This diagnostic was designed after the registered 36 continuations were scored. In that schedule the six test-mask indices alternate between off/off being inactive and active. The first three indices are i, j and (i+j) modulo six. Consequently all 36 have even parity for the number of preceding edits that switch at off/off. A controller that repeatedly interprets the first row as the default can make offsetting errors. The prior fourth-depth advantage criterion and its failure remain in the primary record.

Freeze the three arms, three seeds, 64 source tensors, native recipient and scoring keys at their original hashes. Evaluate **all 1,296 ordered four-edit strings** from the six held-out masks, including all intermediate steps. Run no optimizer and select no subset by performance. Expect 648 strings in each parity stratum and 663,552 directional judgments per depth per arm and seed. The native reader is deterministic on the selected soft row and menu; directly replay its blinded packet in a separate process and require byte-identical raw scores, calls and packet binding before using that cache.

Compare a native final choice with the correct action under the last trigger. Compute four-step joint correctness by requiring the corresponding judgment to be correct under each of its four requested triggers at the same source, world and label mapping. An opposed midpoint exchange runs the other source's first edit and the same remaining operations. Since the destination sees no source/history, its outputs are those of the independently evaluated opposed trajectory. Check this reuse directly against the prior explicit swap on the 36 common strings. Report final correct and paired opposed/strict results by parity, including wrong-polarity outputs. Report all-step correctness for the original 36 and for the full product. The diagnostic supports repeated role use for a given bit arm if all three seeds reach 90% native and correct paired reversals in both parity strata, 90% joint four-step correctness and at least a 25-point overall native gain over the no-bit endpoint. A pass concerns these frozen controllers and known full task domain. The fourth-depth primary and RL-superiority decisions are unchanged. No independent participants or new semantic domains are added.
