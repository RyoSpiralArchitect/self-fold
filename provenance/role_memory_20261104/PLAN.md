# Learn which branch to carry into the next edit

## Question and fixed scope

In the [preceding experiment](../state_only_20261104/RESULTS.md), the branch at off/off was always the default. Here any world can activate either branch. Can a controller that writes its own one-bit message keep the roles of two actions through repeated trigger replacements? Does outcome-reward training outperform a supervised controller on unseen compositions at the same rollout budget? These are separate endpoints. The study tests role orientation in a finite interface.

A nonconstant four-bit edit instruction specifies the worlds that should use the switched action. The bit at position zero corresponds to off/off, then off/on, on/off and on/on. The caller supplies this instruction and a later world address. The learned controller is responsible for reading both branch identities from its current state and leaving usable information for the next edit. An independent native Gemma recipient reads the final action row and two displayed options. No original words, topic, prior operation or target labels enter the next controller call.

## Representation and training

* Reuse the frozen Gemma-2-2B-IT compiler and frozen lexical native reader, bound by the new [fixture](../../data/role_memory_20261104.json). Both were previously developed on all eight topics. A question-free initial state is the ordinary four-row both-on table. Its bit starts at zero. After each edit the only recurrent state is four continuous action rows and the written bit.
* The two row pointers share a content feature, each row's L1 distance from the first row divided by the maximum distance in that table (floor 1e-12). This supplied feature separates the two row contents. The input bit selects two learned scalar gains. Each gain scores all four addresses for one role; the sign and magnitude are learned. The writer is an affine function of the four centered bits of the current instruction. It emits one discrete bit. Nine FP32 parameters are trained. Given the two selected continuous rows, the instruction mask places them in the new worlds. A row with the same action at every address cannot be repaired by the pointer alone.
* Three arms share this model. **Teach the roles** (`supervised`) maximizes the mass on the correct default and switched action under the two pointing distributions. It also receives the off/off truth of the first edit as a one-bit writing target. **Learn from choices** (`reward`) uses sampled-action policy gradients. A fixed environment scores the actual native Gemma choice under both displayed label orders for each selected role. Equal role weights give one scalar reward per edit. First-step pointers receive both rewards; the first written bit and second pointers receive the second reward. Use leave-one-out batch baselines. There are no pointer, action-identity or correct-bit targets in this arm's active loss. **No carried bit** (`table_only`) fits the supervised architecture with the incoming bit forced to zero at each boundary. Its writer is disconnected from later predictions.
* Every arm trains on its own sampled two-edit trajectories. Both categorical row draws and the binary writer use a 12% uniform exploration mixture. Evaluation uses deterministic most likely choices, breaking row ties by lowest index and bit ties to zero. Train from the same small random initialization per seed, using Adam with learning rate .06 and clip one. Three independent seeds 17, 41 and 73, 512 updates, 128 episodes per update (65,536 episodes, 131,072 edits per arm and seed). Same source addresses, masks, noise, parameter counts, forward shapes and optimizer schedule for each pair; sampled trajectories may differ. Both objective expressions execute on the same shapes. The inactive guided expression uses fixed dummy targets for reward learning. Original Gemma outputs are evaluated once per distinct row/menu/order, exactly reusable because the controller only copies continuous rows. Record shared physical model forwards and logical budgets separately. This is a comparison of these schedules and feedback channels, not an estimate of the cost of providing supervision.
* Use the existing three fitting name pairs and three familiar styles. Only archive, notes, length and mail sources enter controller training (144 sources). The other four action menus remain unseen by the controller fit. Eight fitting masks in four complement pairs have one or three switched worlds. Six unseen masks, all balanced two-versus-two, form three new complementary pairs. No constant mask is used. Save and replay all nine final controllers before fresh source capture or scoring. No search, early stopping or retries for an unfavorable seed.

## Held-out native tests

Use all eight known topics, two new name pairs, one familiar grammar, both source orders and both assignments (64 sources, 16 policy bindings). The unseen names and masks are fixed in the fixture. Primary readouts are at depths two and four. Take all 36 ordered pairs of the six test masks. Each has one prespecified two-edit extension, determined by the indices in the frozen generator. Depth one is a diagnostic. There are 18,432 native decisions per route at each primary depth per arm and seed; depth one has 3,072. A strict unit fixes menu and lamp pair and requires all 1,152 judgments across assignments, source orders, sequences, worlds and labels; there are 16 units per depth. Report fitted and controller-withheld menus and each sequence cell. Development sources share a familiar action bank and one fixed grammar.

Run matched and independently encoded opposed sources, an equivalent source (other lamp names, reversed clause order), zero and complemented message at the first edit boundary, and physical omission of the particular last edit being scored. All following edits see only the supplied state. In each opposed comparison, require both native choices to be correct and a strictly reversed A/B margin. Score changed and preserved worlds against the preceding trigger. Record valid letters and retain every attempted decision.

**Identical-table histories.** Assemble a table from each real source's two original soft rows under each of three first masks. Give that very same numerical table to a second history with the two role identities exchanged and the first mask complemented. These are constructed twins. They use each history's learned written bit. Issue all six next edits to both histories at both label orders. Intervene by replacing both bits with zero. The resulting inputs are identical while their correct answers are opposed. Any deterministic table-only choice can therefore satisfy at most half of these 18,432 directional decisions and zero of the 9,216 both-correct pairs. This exact bound belongs to the constructed twins, separately from the ordinary rollouts on independent sources.

**Decision rules.** For an arm to support learned role continuity, each of the three seeds must meet all the following criteria at each primary depth. Native accuracy and correct opposed reversals must each reach 90% in every sequence cell. Correct matched-plus-equivalent outcomes must reach 90% overall. At least 75% of strict units must pass. On changed worlds the update must gain 50 points over bypass, and accuracy on preserved worlds must reach 90%. Native accuracy must exceed the fitted table-only arm by 25 points at the same depth and seed. Intact constructed twins must meet 90% both-correct paired reversals, and erasing the bit must yield identical selected rows in both histories, at most 50% directional accuracy and zero paired successes. Separately, an RL advantage requires at least five points mean gain over supervised depth-four native accuracy, a gain on two or more seeds, zero losses on the third and no strict-unit loss on any seed. Record each arm and seed regardless of gate outcome. This study trains a small controller on a formal policy bank; broad reasoning transfer and unrestricted language recurrence require separate evidence.
