# Learning what the next edit will need

Two walkers can have the same current action table and still need different future edits. One switches to the river when the right lamp is on and otherwise takes the ridge. The other switches to the ridge when the right lamp is off and otherwise takes the river. Their routes match in every current world. Replace both triggers by “left lamp on” and the two now choose opposite routes. The experiment asks whether the controller can learn to retain which action was the default.

## Registered comparison

The frozen Gemma-2-2B-IT compiler and native A/B reader came from the [previous experiment](../state_only_20261104/RESULTS.md). The new nine-parameter controller learned to point at two existing rows and to write one bit for its next invocation. Its read features are the bit and the normalized distances of the rows from off/off. Off/off can now contain either role. The four-bit world mask for the requested edit and the copying of selected rows into that mask are supplied. No previous mask, original text, source identity, action ID or later world reaches the next pointer. The two-way interface and the source and recipient's familiar 16-action vocabulary are substantial scaffolds.

Three arms trained on two-edit trajectories that each sampled for itself. **Teach the roles** (`supervised`) received action labels and the correct role of off/off as the writing target. **Learn from choices** (`reward`) used sampled policy gradients, receiving a scalar native-choice reward after each edit. The first bit received credit only from the next edit's reward. **No carried bit** (`table_only`) had the supervised objective and a zeroed recurrent bit. For each of three seeds the arms had the same initial weights, source samples, edit masks, random draws, architecture, update count and sampled-edit budgets. They used 65,536 two-edit episodes apiece, with 512 Adam updates and a 12% exploration mixture. This matches scheduled work within this controller. Supervision conveys additional information. Gemma's weights, source compiler and native reader were frozen. [Protocol and criteria fixed before fitting](PLAN.md) · [Execution source](https://github.com/RyoSpiralArchitect/self-fold/tree/00104f747316d77f91e4aa143eed0231272e63b9)

Controller training used 144 source realizations from four menus and eight trigger masks, each active in one or three worlds. Test used 64 descriptions of 16 policies, all eight familiar menus, two new name pairs, one familiar syntax and six previously unseen masks active in two worlds. Reversed clause orders and A/B mappings stayed paired. The extra four topics were unseen by the controller fit and familiar to the frozen compiler and recipient. Every count below is **per seed**. Seeds 17, 41 and 73 gave identical native counts.

Both bit arms passed the per-sequence native and correctly reversed opposed-donor checks at both depths. Replacing the first intermediate with an equivalent donor preserved every correct native answer. Erasing the first message gave 9,216/18,432 at each depth. Complementing it produced the correct original plus the opposite choice on all 18,432 directions at each depth. For these arms the update solved all 9,216 changed-world judgments at either depth and omission solved none, while all 9,216 preserved-world judgments remained correct. The four menus excluded from controller fitting contributed 9,216 perfect matched decisions at either depth.

In the twin control the experimenter provided the *exact same FP32 table* in two histories obtained by complementing the first trigger and exchanging the two role assignments. They retained the different bits produced by the corresponding learned writers. The next operation, displayed alternatives and world were identical. With the bit, both arms got both opposed answers correct with a reversed margin on every one of 9,216 pairs. Erasing the bit made all addressed rows pairwise identical, gave exactly 9,216/18,432 directional correct choices and zero both-correct pairs. A deterministic table-only reader has a 50% ceiling for these balanced constructed twins. The ordinary independently encoded donor experiment has a separate denominator.

The learned writers of both bit arms emitted the truth of the first world under all 14 nonconstant instructions. In each of these six controllers a zero bit made the default pointer favor a row close to the first row and the switched pointer favor a distant row. A one bit exchanged these signs. Thus scalar feedback found the same binary convention explicitly taught in the supervised arm. The relevant message is one coordinate of the supplied mask. The learning problem is to route it to the next edit and use it to choose the row addresses. These correct decisions cleared the accuracy and strict-unit cutoffs. The primary gate also required an advantage over the no-bit control. The no-bit control tied both bit arms at the registered fourth endpoint, eliminating the required 25-point advantage. **The primary joint gate failed**, and reward training's fourth-step advantage over the supervised baseline was zero points at every seed. ## Why final correctness hid errors

The registered depth-four generator used pairs of mask indices i and j and then index (i+j) modulo six. Even indices have the off/off bit zero and odd indices have it one. Thus the first three masks in each registered string have an even number of ones at this address. The no-bit controller treated the first row as the default at every step. Each preceding off/off activation could exchange the roles, and two such exchanges canceled at the fourth edit. At the original 36 strings, only 4,608/18,432 no-bit trajectories were correct at every step despite 18,432 correct terminal choices.

After observing this parity pattern we sealed an exhaustive follow-up at the same nine endpoints. It evaluates all 1,296 four-edit strings over the six test masks, with 648 in each parity stratum. Every source, question, scoring rule and trainable weight was held fixed. The blind native packet was rescored in a new process with byte-identical full-vocabulary winners, A/B scores, dispatch and input fingerprints. The previous 36 matched and explicit opposed trajectories reproduced exactly. The follow-up reuses the original sources and native queries. Each count is per seed, with 64 sources × 1,296 strings × four worlds × two labels. These are repeated queries of 16 policies. The original joint decision remains failed. The observation demonstrates a learned one-bit convention for repeated use in this interface, with no measured benefit of the reinforcement objective over role supervision. ## Evidence and limits

The source and reader hashes, identical per-seed schedules, all 4,608 optimizer steps and the frozen-before-test boundary are archived. Every downstream table row is a bitwise copy of an original continuous Gemma action row. Only after running the actual tensor updates did the producer replace each output by its exact row address. Native rendering uses the original continuous vector. Fitting shared 412 distinct source-row/menu/label inputs and evaluation shared 196. The producer recorded 40 model forwards and the blind test reader recorded 13. The hundreds of thousands of logical paths are not independent language-model calls or independent observations of transfer. [Native test inputs and scores](run/decide/native.json) · [Replay and parent bindings](full/binding.json) · [Reproduction commands](../../docs/REPRODUCING.md)

There are two actions to distinguish, a supplied reference for comparing the rows, an explicit bit channel and a complete trigger mask at every edit. Larger action sets, textual edit instructions, decisions to stop, unseen source grammar and the original open-ended language/slot recurrence each need a separate test. A useful next comparison would vary the number of role assignments and the available memory, hold out entire policy families and score correctness at every prefix under balanced histories.
