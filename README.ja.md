# SELF-FOLD

[English](README.md) · 日本語

**現在の自己記述を解釈し直して得た区別は、次の更新と、その後の判断を支えられるか。** SELF-FOLDは、その連続性と、途中で言語化を挟むことの影響を調べます。更新に渡すのは現在の記述か、固定数の潜在スロットだけです。過去の発話は実験者が外部に記録し、学習する接続部品は評価前に固定します。

| 条件 | 次のステップに渡すもの |
| --- | --- |
| T・文章 | モデルが新しく書いた自己記述。 |
| L・潜在状態 | 内部で1回更新した8個のスロット `G(Z)`。 |
| B・言語化往復 | Lと同じ更新を行い、その結果を文章にしてもう一度符号化したスロット `E(D(G(Z)))`。 |

LとBは同じ初期状態、更新演算、層の境界、生成の停止規則を使います。この特定の言語化往復で何が変わり、その変化が後の課題にどう響くかを調べています。[論文PDF](paper/self-fold.pdf) · [ブラウザで読む](paper/main.md) · [実験プロトコル](docs/PROTOCOL.md)

プレプリント初版（v1.0.0）の著者は Ryo Higa（SpiralReality, Enginee, inc.）です。[Zenodoの論文DOI](https://doi.org/10.5281/zenodo.23930929) · [論文PDF](paper/self-fold.pdf)

## 再現手順

リポジトリをクローンし、Python 3.11以降で以下を実行します。

~~~bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev,hf]'
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 python -m pytest -q
bash scripts/run_smoke.sh runs/tiny-001
~~~

試行ごとに新しい出力先を指定します。実験記録にはソースコミット、モデルの識別情報、採点前の生スコア、生成の停止理由を残しています。[学習済みモデルでの再現とファイルの照合](docs/REPRODUCING.md) · [モデルと状態の実装](docs/ARCHITECTURE.md) · [意味を検証する基準](docs/QUALIFICATION.md)

[意味ゲートまでの研究計画](docs/SEMANTIC_GATE_PLAN.ja.md)では、質問に依存しない状態の検証、E/Dなどの学習、独立した通過挑戦までを6課題にまとめています。各課題に、肯定的な完了条件と、未達の範囲を記録して次へ進める条件を置いています。現在の足場は、採否の役割→行動との結合→条件付きの利用→実際の二段更新→中間状態の言語化、という一本線です。原文の段階学習を終え、まず全状況で安定して条件を使い、選択肢順が変わってもnative回答を対応させる学習が残っています。Gによる妥当な1回更新と、独立した資格試験はこれからです。
